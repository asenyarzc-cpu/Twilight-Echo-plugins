# Twilight Echo · 汽水音乐 Provider

纯插件实现，不需要额外运行 qishui-api。

## 登录

插件通过宿主提供的汽水 Passport 安全桥接调用二维码接口。宿主会在主进程初始化上游安全组件，生成动态 `msToken` / `a_bogus` 请求参数；扫码轮询同时兼容 Set-Cookie、响应体 `sessionid` / `auth.sessionid` / `session_cookie`。旧版宿主没有该桥接时保留纯网络回退流程。

使用抖音 App 扫描二维码并完成确认。

## 功能

- 品牌主页：发现好音乐、官方推荐歌单、登录后展示我的喜欢

- 扫码登录
- 登录状态
- 账号资料
- 我的歌单
- 歌单歌曲
- 歌曲搜索
- 歌单搜索
- 歌词
- 播放地址

## 说明

0.4.6：修复封面只返回 CDN 目录的问题，按上游 `urls + uri` 拼接图片并追加裁剪参数；保留已经完整的头像和签名图片地址。账号资料改为宿主契约的 `userId` / `avatarUrl` 字段，使头像可以通过宿主图片协议加载。主页通过宿主 `streamingSections` 接入“发现好音乐”和“我的喜欢”，推荐歌单来自 `/luna/discover/mix`，公开歌曲选自这些歌单，不标记为个性化每日推荐。公开主页无需登录，喜欢的歌曲仅在登录后加载。主页最多展示十二张歌单和十二首分区歌曲，只读取歌单首屏，不为主页扫描整张歌单。

0.4.5：修复搜索与个人音乐库引用未定义设备变量导致的异常；歌曲和歌单搜索切换到实测可用的 `/luna/search/*` 接口，携带当前登录态并解析分组结果。个人资料识别 `my_info`，歌单详情保留登录态和歌单类型，支持游标分页。空响应和上游业务错误会明确报错。

播放先请求账号 PC 播放信息并解析实际音频地址；账号接口不可用时读取官方分享页提供的未加密音频。付费歌曲可能只提供试听片段，登录不代表当前接口可获取会员完整音频。插件设置面板会显示此限制，不再将任意封面或 JSON 地址作为音频返回。

汽水音乐接口属于非公开接口，字段或鉴权策略改变后需要更新插件。
本插件不提供下载、破解、DRM 绕过或会员限制绕过。

## 登录实现

二维码登录使用汽水 Passport 接口。二维码内容使用官方 PC `scan_login` 地址，扫码后由抖音 App 完成确认。`qishui-auth-v6.cjs` 依赖 Electron `BrowserWindow`，由 Twilight Echo 主进程安全桥接加载；插件宿主只接收二维码 DTO、轮询 JSON 和脱敏会话 Cookie，不直接接触 Electron。

0.2.7：修复扫码 404：上游 `qrcode` 若为二维码图片/图片 Base64，则直接作为 `imageDataUrl` 展示，避免把二维码图片内容再次编码成二维码；登录请求参数同步到当前抖音 Passport 文档格式。

0.3.0：改用当前汽水 PC 扫码入口。二维码不再指向抖音 Passport，而是根据汽水返回的 `qrcode_index_url` 提取 token 后生成 `https://bff-pc.qishui.com/light/invoke/scan_login` 扫码地址；PC 参数更新到 SodaMusic 3.1.2 / version_code 3.6.0。

0.4.0：同步汽水 Passport/PC 二维码接口参数，使用官方返回的 `qrcode_index_url`；不需要运行 qishui-api。

0.4.3：同步上游 PC Passport 的动态设备标识、请求头和表单摘要，兼容更多登录 Cookie 名称；扫码后遇到临时 1049 状态时保留已扫码状态，并增加脱敏的上游错误描述。

0.4.4：接入宿主侧汽水安全登录桥接，使用上游动态安全参数完成二维码生成和扫码轮询；保留旧版宿主的纯网络回退，并直接展示安全组件生成的二维码图片。

0.4.2：增加脱敏的二维码生成/轮询诊断日志，便于识别网络错误、上游状态和会话返回位置。

0.4.1：修复官方 PC `scan_login` 二维码地址遗漏，以及扫码确认后的会话只出现在响应体时桌面端无法识别登录的问题；现在兼容 `Set-Cookie`、`sessionid`、`auth.sessionid` 和 `session_cookie`。
